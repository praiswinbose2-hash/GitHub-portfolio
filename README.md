An innovative spatial cyber-architect portfolio featuring interactive WebGL particles, custom physics cursor, live command console, and capability matrix.

---

## ⚡ Features

- **Spatial Dark Cyber Theme**: Tailored HSL dark palette with neon emerald and ultraviolet accents.
- **Interactive Canvas Particles**: 60FPS background particle mesh reactive to cursor velocity and proximity.
- **Custom Spring Cursor**: Fluid ring and pointer with magnetic attraction to interactive elements.
- **Interactive Terminal Console**: Embedded command line runner with real-time feedback.
- **Dynamic Projects Showcase**: Categorized full-stack works with interactive architecture inspector.
- **Signal Transmit Channel**: Contact system with instant email copy and API transmission.
- **Live IST Telemetry**: System region and local Indian Standard Time clock in the footer.

---

## 🛠 Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons
- **Backend**: FastAPI, Python 3.9+, Pydantic v2, SQLite, SQLAlchemy
- **Deployment**: GitHub Pages (Universal build) + CORS support

---

## 🚀 Local Development

### 1. Backend
```bash
cd backend
source .venv/bin/activate
uvicorn main:app --reload --port 8000
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
